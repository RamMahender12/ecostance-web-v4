# EcoStance Web

Product marketing site for EcoStance — AI-native SaaS for Digital Product Passports, fashion/apparel supply-chain traceability, cross-border commerce, and trusted carbon disclosure.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Checks

```bash
npm run check:chat
```

Product imagery: `public/products/`, `public/brand/`, `public/from-ebcopen/` (imported from test.ebcopen.com). Hero collage: `public/video/hero-collage.mp4`.
